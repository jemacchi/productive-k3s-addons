# Productive K3S Addons

`productive-k3s-addons` is the public home of curated packages that extend a Productive K3S cluster.

If you want ready-to-use cluster capabilities first, start here.

Examples available today include:

- `Rancher`
- `Longhorn`
- `Registry`
- `Cert-Manager`

Behind that product view, this repository is also the public source consumed by `productive-k3s-core` for addon and stack package installation.
