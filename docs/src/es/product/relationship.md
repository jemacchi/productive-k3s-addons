# Relación con Core y Addons Pro

`productive-k3s-core` es el engine de instalación de las extensiones curadas del cluster definidas acá. Descubre metadata de add-ons, resuelve la pertenencia a stacks y ejecuta hooks normalizados.

`productive-k3s-addons` contiene:

- `addons/`: capacidades curadas del cluster que pueden instalarse individualmente
- `stacks/`: caminos curados de extensiones agrupadas construidos a partir de esos add-ons

`productive-k3s-addons-pro` sigue el mismo contrato de repositorio para contenido privado.
