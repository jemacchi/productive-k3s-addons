# Documentación para usuarios

Esta sección explica cómo consumir la capa curada de addons y stacks.

En el flujo normal orientado a usuarios, los operadores instalan esos paquetes mediante `pk3s` o `productive-k3s-core`.

El authoring y la validación a nivel repositorio siguen importando, pero son secundarios respecto de la idea principal: este repositorio ofrece extensiones listas para usar dentro del cluster.
