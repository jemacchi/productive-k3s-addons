# Productive K3S Addons

`productive-k3s-addons` es la casa pública de los paquetes curados que extienden un cluster Productive K3S.

Si querés primero capacidades listas para usar dentro del cluster, empezá acá.

Hoy hay ejemplos como:

- `Rancher`
- `Longhorn`
- `Registry`
- `Cert-Manager`

Detrás de esa vista de producto, este repositorio también es la fuente pública que consume `productive-k3s-core` para instalar paquetes de addons y stacks.
